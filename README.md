# 🎬 SplitVideo

**SplitVideo** es una aplicación de escritorio ligera y funcional diseñada para dividir tus videos largos en segmentos perfectos de manera automática y totalmente local en tu computadora.

---

## ✨ Características Principales
* 🚀 **Fácil de usar:** Interfaz gráfica intuitiva basada en Python y Tkinter.
* 📦 **FFmpeg integrado:** No requiere instalaciones complejas ni descargar herramientas adicionales; incluye todo lo necesario para procesar los videos.
* ⏱️ **Control total:** Define la duración exacta (en segundos) de cada segmento de video con total precisión.
* 🔒 **Procesamiento local:** Tus archivos nunca se suben a la nube, garantizando tu privacidad.

---

## 📥 Descarga e Instalación

1. Dirígete a la sección de **[Releases](https://github.com/softwareMLand/splitvideo/releases)** de este repositorio.
2. Descarga el archivo ejecutable **`DivisorVideo.exe`** correspondiente a la última versión.
3. Haz doble clic en el archivo descargado para iniciar la aplicación.

> **Nota de seguridad (Windows SmartScreen):** 
> Al ser una aplicación independiente y no estar firmada con un certificado de pago comercial, Windows podría mostrar una alerta de pantalla azul indicando *"PC protegido por Windows"*. Esto es completamente normal; solo debes hacer clic en **"Más información"** y luego en **"Ejecutar de todas formas"**.
