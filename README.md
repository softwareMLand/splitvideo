## 📖 Acerca de SplitVideo

**SplitVideo** es una aplicación de escritorio ligera y funcional, desarrollada en Python, que te permite automatizar la tarea de cortar videos. Olvídate de procesos manuales complejos; con SplitVideo, solo necesitas indicar el video de entrada, la duración deseada para cada segmento (en segundos) y la carpeta de salida.

La aplicación utiliza la potencia de **FFmpeg** (incluido internamente) para realizar los cortes de manera rápida y sin pérdida de calidad. Todo el procesamiento se realiza de forma local en tu computadora, garantizando la privacidad de tus archivos.

## 🚀 Características Principales

*   🎥 **Corte Automático:** Divide videos largos en múltiples segmentos de igual duración con un solo clic.
*   ⚙️ **FFmpeg Integrado:** No requiere instalaciones adicionales ni configuración de entorno. La aplicación viene lista para funcionar.
*   🔢 **Control de Precisión:** Define la duración exacta de los segmentos en segundos enteros.
*   🖥️ **Interfaz Intuitiva:** Interfaz gráfica de usuario (GUI) simple y fácil de usar para cualquier persona.
*   🔒 **Privacidad Total:** Los archivos de video nunca salen de tu dispositivo.
*   ⚡ **Rápido y Eficiente:** Utiliza la eficiencia de FFmpeg para un procesamiento veloz.
